Sygnet QMS is a queue management system in three tiers. QMS Lite is hardware based: segment token displays and a call pad, on LAN and Wi-Fi, for basic features and low budgets. QMS Professional is touch kiosk and software based, with an operator console, token displays and advanced features. QMS Enterprise is cloud based, bought and used at once on a yearly subscription. Sygnet IoT is based in Surat, Gujarat, India.
